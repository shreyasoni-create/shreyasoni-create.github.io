How I approach a build

From reference to real storefront.

I focus on the details that make a design work in a real Shopify theme — for customers and for the merchant managing it.

01 / UNDERSTAND

Review the design

Identify shared patterns, responsive behavior, and where a native theme section works versus where a custom section is needed.

02 / BUILD

Make it configurable

Build with Liquid, HTML, CSS, and JavaScript, using section schema and settings so content can be managed in the theme editor.

03 / REFINE

Test across screens

Check desktop and mobile layouts, interactions, and visual details; debug in browser DevTools and refine the experience.
